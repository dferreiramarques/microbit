Atividade 004 · Acelerómetro, limiares, nível iniciação

Passo

O acelerómetro mede a força de cada movimento. Decidir a partir de que força isso conta como "passo" é uma escolha — e a mesma escolha não serve para uma criança de seis anos e para um adulto a correr.

Passos contados 0
Acelerómetro · força 0–2000 1 variável editável Sem rádio Um aparelho por pessoa
O mecanismo

Medir a força,
não o movimento

O micro:bit não sabe o que é um passo. Só sabe medir a força total a que está sujeito, muitas vezes por segundo, e comparar esse número com um limiar.

A cada instante

Mede a força

input.acceleration(Strength) devolve um número que sobe com qualquer abanão, passo ou salto — e também com tremores da mão.

Comparação

Passou o limiar?

Se a força medida for maior ou igual ao limiar, conta-se um passo e soma-se ao total.

Botão B

Reinicia a contagem

Zera o contador para começar uma nova ronda sem desligar o aparelho.

Conceito

Falsos positivos,
falsos negativos

Um limiar baixo conta abanões de braço como passos — falso positivo. Um limiar alto ignora passos suaves de quem anda em bicos de pés — falso negativo. Não existe um limiar perfeito, só um que serve melhor para uma situação.

LimiarEfeito
600Conta quase tudo, incluindo movimentos que não são passos
1200Equilíbrio razoável para andar normalmente
1800Só conta passos fortes ou saltos; passos suaves desaparecem

Preparação

Um aparelho,
bem preso

Não há configuração por aparelho — todos correm o mesmo código. A única preparação é física: o micro:bit precisa de andar preso ao corpo, não solto na mão, para as leituras serem consistentes.

Onde prenderNota
BolsoSimples, mas o tecido amortece a força — usar limiares mais baixos
Braçadeira ou fitaLeituras mais nítidas, precisa de material extra
Na mão, bem seguraSó para a fase de teste, não para a corrida
Programa

Código MakeCode

No MakeCode, abrir o separador { } JavaScript, colar, e voltar a Blocos. Cada equipa cola isto inteiro e edita só uma coisa, a seguir, passo a passo.

passo.ts · acelerómetro + limiar 
// ===== PASSO — microbit.monco.io =====
// conta um passo sempre que a força passa o limiar

// >>> A EQUIPA ESCOLHE AQUI <<<
let LIMIAR = 1200

let passos = 0

function verificarPasso() {
    let forca = input.acceleration(Dimension.Strength)
    if (forca >= LIMIAR) {
        passos = passos + 1
        basic.showNumber(passos)
        music.playTone(880, music.beat(BeatFraction.Sixteenth))
    }
}

basic.forever(function () {
    verificarPasso()
    basic.pause(150)
})

input.onButtonPressed(Button.B, function () {
    passos = 0
    basic.showIcon(IconNames.Target)
})

O limiar

LIMIAR é o único valor do programa — a força mínima, numa escala que costuma ir até cerca de 2000, para contar como passo. Quanto mais alto, mais forte tem de ser o movimento.

// >>> A EQUIPA ESCOLHE AQUI <<<
let LIMIAR = 1200
02
Já vem assim

Medir e comparar

Sessenta vezes por segundo — a cada 150 milissegundos — o programa lê a força e compara com o limiar. Se passar, soma um ao contador, mostra-o e toca um som curto.

basic.forever(function () {
    verificarPasso()
    basic.pause(150)
})

Já vem assim

Reiniciar

O botão B zera o contador — é o que se carrega entre rondas, sem precisar de reprogramar nada.

input.onButtonPressed(Button.B, function () {
    passos = 0
    basic.showIcon(IconNames.Target)
})

Uma edição só, sempre a mesma: o valor de LIMIAR, no passo 01, entre rondas de teste.

Resolução de problemas

SintomaSolução
Conta passos sem ninguém se mexerAparelho a vibrar em cima de uma superfície — pousar num sítio estável ou baixar o limiar
Não conta passos suavesDescer o limiar em passos de 100 até aparecerem

Se sobrar tempo

Para onde
isto pode ir

  • Debounce — ignorar novos passos durante 300 ms depois de contar um, para não contar duas vezes a mesma passada
  • Distinguir gestos — usar input.onGesture para separar "salto" de "passo" por forma da curva, não só pela força
  • Rádio — cada aparelho envia o seu total e um ecrã central soma os passos de todo o grupo
