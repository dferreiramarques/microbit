Bússola

Sem rádio, sem equipa, sem ninguém a coordenar. Cada micro:bit só sabe uma coisa — para onde aponta — e mostra um visto quando essa direção está perto o suficiente do norte. O grupo inteiro gira até virar uma roseta de bússolas.

N
Rumo 0° Alinhado

Arrasta a agulha para girar. As duas linhas tracejadas marcam os limites da tolerância.

Magnetómetro · 0°–359° 1 variável editável Sem rádio 6 a 10 pessoas
O mecanismo

Uma direção,
uma diferença

Não há troca de informação entre aparelhos. Cada um calibra-se sozinho, lê o seu próprio rumo, e decide sozinho se está alinhado.

Uma vez

Calibra

Ao ligar, o micro:bit pede para ser inclinado em todas as direções — é assim que aprende onde está o norte magnético a partir daquele ponto exato da sala.

Sempre

Lê o rumo

Devolve um número de 0° a 359°, onde 0° é norte magnético e os valores sobem no sentido dos ponteiros do relógio.

Comparação

Está perto?

Calcula a diferença entre o rumo atual e o alvo, e mostra um visto se essa diferença estiver dentro da tolerância.

Conceito

0° e 359°
são vizinhos

Numa régua normal, 358 e 2 estão longe um do outro. Numa bússola, 358° e 2° estão a só quatro graus de distância — o círculo dá a volta. Sem tratar esse caso, o programa pensaria que apontar quase para norte pelo lado errado é o mesmo que apontar para sul.

Rumo ARumo BDiferença real
10°350°20°
90°270°180°
5°355°10°

É por isto que o código, mais abaixo, corrige a diferença sempre que ela passa de 180°.

Preparação

Longe
de metal

Não há configuração por aparelho — todos correm o mesmo código. A preparação é do espaço: mesas de metal, portáteis e colunas de som desviam o magnetómetro.

Programa

Código MakeCode

No MakeCode, abrir o separador { } JavaScript, colar, e voltar a Blocos. Cada equipa cola isto inteiro e edita só uma coisa, a seguir, passo a passo.

bussola.ts · magnetómetro + tolerância 
// ===== BÚSSOLA — microbit.monco.io =====
// alinhar com o norte magnético, dentro de uma tolerância

let ALVO = 0

// >>> A EQUIPA ESCOLHE AQUI <<<
let TOLERANCIA = 15

input.calibrate()

basic.forever(function () {
    let rumo = input.compassHeading()
    let diferenca = Math.abs(rumo - ALVO)
    if (diferenca > 180) {
        diferenca = 360 - diferenca
    }
    if (diferenca <= TOLERANCIA) {
        basic.showIcon(IconNames.Yes)
    } else {
        basic.showIcon(IconNames.No)
    }
    basic.pause(200)
})
Guião do dinamizador

O código,
passo a passo

Três passos. A calibração é a única parte que pede um gesto especial de cada aparelho, antes de começar a atividade.

01
Já vem assim

Calibrar

input.calibrate() corre uma vez, ao ligar. Pede para inclinar o aparelho até acender todos os LEDs à volta do ecrã — é assim que aprende onde é o norte a partir daquele ponto da sala. Repetir se o aparelho mudar de sítio.

input.calibrate()
02
Edita aqui

A tolerância

TOLERANCIA é o único valor que se muda — quantos graus para cada lado do norte ainda contam como alinhado. Um número pequeno exige mais precisão.

// >>> A EQUIPA ESCOLHE AQUI <<<
let TOLERANCIA = 15
03
Já vem assim

Corrigir a volta ao círculo

A diferença entre dois rumos pode dar mais de 180° por engano, se não se corrigir — é o caso de 359° e 1°. A linha se maior que 180, subtrai a 360 resolve isso, sempre.

let diferenca = Math.abs(rumo - ALVO)
if (diferenca > 180) {
    diferenca = 360 - diferenca
}

Uma edição só, sempre a mesma: o valor de TOLERANCIA, no passo 02, entre a primeira ronda e a ronda mais apertada.

Para onde
isto pode ir

  • Alvo diferente de norte — mudar ALVO para apontar a um objeto fixo da sala em vez do norte magnético
  • Farol por rádio — um aparelho transmite o seu próprio rumo, e os outros alinham-se com ele em vez de um valor fixo
  • Distância ao alvo — mostrar uma seta a apontar para que lado girar, em vez de só sim ou não
