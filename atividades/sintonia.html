Atividade 001 · Som, rádio e sistemas distribuídos

SINTONIA

Dez micro:bits. Cada um sabe tocar duas notas e mais nada. O acorde não vive dentro de nenhum deles — aparece no espaço entre três pessoas que se aproximam ao mesmo tempo.

O mecanismo

Três decisões locais,
um resultado partilhado

Nenhum micro:bit tem uma visão do conjunto. Cada um só sabe o que ouve à sua volta — e é dessa soma de decisões isoladas que o acorde emerge.

Botão A ou B

Assume uma nota

Cada aparelho guarda duas notas: uma da Lista A, outra da Lista B. Ao carregar, toca a nota e passa a anunciá-la por rádio a cada meio segundo.

Rádio + RSSI

Ouve quem está perto

Recebe as notas dos outros, mas só guarda as que chegam com sinal forte. As distantes são descartadas, mesmo tendo chegado.

Tríade completa

Dispara o acorde

Quando as três classes de nota do seu acorde estão presentes, envia o sinal TOCA e os três soam em conjunto.

Amplitude

A mesma nota,
alturas diferentes

Cada lista passou de 3 para 9 notas, distribuídas por três registos. O DÓ3 a 131 Hz e o DÓ5 a 523 Hz são frequências completamente diferentes — mas são a mesma nota, e valem o mesmo para o acorde.

O programa compara classes de nota, não frequências: corta o algarismo do fim e fica com DO, MI, SOL. Um DÓ3 grave, um MI4 e um SOL5 agudo formam uma tríade tão válida como três notas coladas — e soam bastante melhor, porque ficam espalhadas em vez de amontoadas.

Proximidade

O que é o filtro RSSI

O rádio do micro:bit atravessa a sala inteira. Sem filtro, os dez aparelhos ouviam-se todos e os acordes formavam-se sozinhos, sem ninguém dar um passo.

Cada pacote recebido traz a sua própria força de sinal, em dBm — sempre um número negativo, em que menos negativo significa mais perto. O programa lê esse valor e decide se vale a pena guardar a nota. A mensagem chega na mesma; é o código que a deita fora.

1,8 m −42 dBm Nota aceite

Simulação aproximada. Na sala real, corpos, paredes e a orientação da antena alteram os valores — daí a calibração fazer parte da atividade.

  • −40 dBm — encostados, menos de um metro
  • −55 dBm — dois a três metros. É o limiar usado por omissão
  • −70 dBm — cinco a oito metros, do outro lado da sala
  • −90 dBm — no limite do alcance, prestes a perder-se

Programa

Código MakeCode

No MakeCode, abrir o separador { } JavaScript, colar, e voltar a Blocos. O código está escrito só com construções que o editor sabe representar, por isso aparece tudo em blocos, pronto a ser explorado e alterado. Cada equipa cola isto inteiro e edita só duas coisas — a seguir, passo a passo.

sintonia.ts · 18 notas · classes de nota 
// ===== SINTONIA — microbit.monco.io =====
// 18 notas, 3 registos, comparação por classe de nota

let NOMES = ["DO3", "MI3", "SOL3", "DO4", "MI4", "SOL4", "DO5", "MI5", "SOL5",
             "RE3", "FA3", "LA3", "RE4", "FA4", "LA4", "RE5", "FA5", "LA5"]
let FREQS = [131, 165, 196, 262, 330, 392, 523, 659, 784,
             147, 175, 220, 294, 349, 440, 587, 698, 880]

let CLASSES_A = ["DO", "MI", "SOL"]   // Acorde 1 — Dó Maior
let CLASSES_B = ["RE", "FA", "LA"]    // Acorde 2 — Ré menor

// >>> A EQUIPA ESCOLHE AQUI <<<
let notaA = "DO3"
let notaB = "RE4"

let PROXIMIDADE = -55
let minhaNota = ""
let ouvidas: string[] = []
let emSintonia = false

// "SOL4" -> "SOL"   (tira o algarismo do registo)
function classeDe(nota: string) {
    return nota.substr(0, nota.length - 1)
}

function freqDe(nota: string) {
    return FREQS[NOMES.indexOf(nota)]
}

function tocarNota() {
    basic.showIcon(IconNames.Heart)
    music.playTone(freqDe(minhaNota), music.beat(BeatFraction.Double))
    basic.showString(minhaNota)
}

function assumirNota() {
    ouvidas = []
    emSintonia = false
    basic.showString(minhaNota)
    music.playTone(freqDe(minhaNota), music.beat(BeatFraction.Half))
}

function verificarAcorde() {
    let minhaClasse = classeDe(minhaNota)
    let oMeuAcorde = CLASSES_B
    if (CLASSES_A.indexOf(minhaClasse) >= 0) {
        oMeuAcorde = CLASSES_A
    }
    let classesOuvidas: string[] = []
    for (let n of ouvidas) {
        classesOuvidas.push(classeDe(n))
    }
    let completo = true
    for (let c of oMeuAcorde) {
        if (c != minhaClasse && classesOuvidas.indexOf(c) < 0) {
            completo = false
        }
    }
    if (completo && !emSintonia) {
        emSintonia = true
        radio.sendString("TOCA")
        tocarNota()
    }
}

input.onButtonPressed(Button.A, function () {
    minhaNota = notaA
    assumirNota()
})

input.onButtonPressed(Button.B, function () {
    minhaNota = notaB
    assumirNota()
})

input.onGesture(Gesture.Shake, function () {
    minhaNota = ""
    ouvidas = []
    emSintonia = false
    basic.showIcon(IconNames.Asleep)
})

radio.onReceivedString(function (receivedString) {
    if (minhaNota != "" && radio.receivedPacket(RadioPacketProperty.SignalStrength) >= PROXIMIDADE) {
        if (receivedString == "TOCA") {
            if (ouvidas.length > 0) {
                tocarNota()
            }
        } else {
            if (receivedString != minhaNota && ouvidas.indexOf(receivedString) < 0) {
                ouvidas.push(receivedString)
            }
            verificarAcorde()
        }
    }
})

radio.setGroup(7)
radio.setTransmitPower(2)
basic.showIcon(IconNames.Asleep)

basic.forever(function () {
    if (minhaNota != "") {
        radio.sendString(minhaNota)
    }
    basic.pause(500)
})

basic.forever(function () {
    basic.pause(4000)
    if (!emSintonia) {
        ouvidas = []
    }
})

O código,
passo a passo

Para ler antes da sessão e apontar durante ela. O programa de cima já vai completo — nenhuma equipa parte de uma folha em branco. O trabalho delas é perceber cinco decisões que ele toma, e mexer só nas duas que lhes pertencem. Tudo o resto é ler em voz alta e mostrar no ecrã do computador.

As duas listas de notas

Duas listas paralelas. Na posição 0 de NOMES está DO3; na posição 0 de FREQS está 131 — a frequência em hertz do DO3. É o dicionário completo: todas as notas que existem no sistema inteiro, com nome e som. Nenhum micro:bit inventa uma nota que não esteja aqui.

Tocar e avisar a sala inteira

Carregar no botão A ou B escolhe a nota e toca-a de imediato. A partir daí, um ciclo em fundo repete-se sozinho: a cada meio segundo, o micro:bit anuncia a sua nota por rádio, quer alguém esteja a ouvir quer não. É esse anúncio contínuo que os outros nove aparelhos vão apanhar.

04
Edita aqui

Só aceitar quem está perto

O rádio ouve a sala inteira, mas cada pacote traz a força do sinal com que chegou — sempre negativa, tanto mais próxima de zero quanto mais perto está quem enviou. PROXIMIDADE é o limiar: abaixo dele, a nota é ignorada, mesmo tendo chegado. É o único valor que se recalibra em sala, depois de testar a distância real com o simulador de RSSI, mais atrás nesta página.

let PROXIMIDADE = -55
// ...

05
Já vem assim

Contar até três

classeDe() tira o algarismo do fim — SOL4 vira SOL — para comparar notas por classe, não por oitava. verificarAcorde() percorre as três classes do acorde da equipa e verifica se já ouviu todas. Quando sim, e só uma vez, envia TOCA por rádio e toca a própria nota. Não há um micro:bit maestro: os dez fazem esta conta ao mesmo tempo, cada um só com a informação que tem.

function classeDe(nota: string) {
    return nota.substr(0, nota.length - 1)
}
// ...
if (completo && !emSintonia) {
    radio.sendString("TOCA")
    tocarNota()
}

Duas edições por equipa, sempre as mesmas: a nota, no passo 02, antes de carregar o programa; o limiar, no passo 04, depois de testar a distância na sala. O resto do código não se mexe.

Para onde isto pode ir

  • Escolha dinâmica — A+B percorre a lista das 9 notas, A confirma. Cada participante escolhe mesmo o seu registo, em vez de o receber
  • Sétimas — juntar SI e DO ao conjunto e exigir quatro pessoas coordenadas em vez de três
  • Regra de amplitude — só validar a tríade se as três notas estiverem em registos diferentes. Obriga a pensar o acorde como espaço, não como lista
  • Monitor central — um 11.º micro:bit ligado por USB regista em série todos os acordes formados e desenha-os em tempo real
  • Saída MIDI — encaminhar as notas por série para um sintetizador ou uma DAW
