Atividade 006 · Microfone, limiares, nível iniciação

Volume

O microfone do micro:bit mede o som em números. Um limiar decide onde acaba o sussurro e começa o grito — e o grupo inteiro tem de cumprir uma tarefa sem o deixar disparar.

Leitura 90 Sussurro
Microfone · 0–255 1 variável editável Sem rádio 8 a 14 pessoas
O mecanismo

Ouvir
e classificar

Cada micro:bit ouve só o som à sua volta e decide, sozinho, se está acima ou abaixo do limiar. Não há um "volume da sala" — há catorze opiniões diferentes sobre o mesmo instante.

Sempre

Mede o som

input.soundLevel() devolve um número entre 0 e 255, medido pelo microfone embutido do V2.

Comparação

Grito ou sussurro?

Compara a leitura com o limiar e mostra uma cara — contente se está calmo, zangada se passou a marca.

Fora do código

O grupo regula-se

Manter todos os ecrãs contentes ao mesmo tempo é trabalho de equipa, não do programa.

Conceito

O limiar depende
do fundo

Um grito numa biblioteca silenciosa e uma conversa normal ao lado de uma rua com trânsito podem dar o mesmo número no microfone. O limiar não mede o som absoluto do mundo — mede a diferença entre estar calmo e estar alto, num sítio e num momento específicos.

LimiarEfeito
80Quase qualquer conversa dispara o alerta
150Deixa passar conversa normal, apanha vozes altas
220Só reage a gritos ou música alta

Preparação

Testar
o fundo sonoro

Não há configuração por aparelho — todos correm o mesmo código. Antes de começar, vale a pena medir o silêncio da sala: com toda a gente calada, ver que número aparece, para calibrar o limiar de forma realista.

SituaçãoLeitura típica
Sala em silêncio20–50
Conversa normal80–140
Voz alta ou grito180–255
Programa

Código MakeCode

No MakeCode, abrir o separador { } JavaScript, colar, e voltar a Blocos. Cada equipa cola isto inteiro e edita só uma coisa, a seguir, passo a passo.

volume.ts · microfone + limiar 
// ===== VOLUME — microbit.monco.io =====
// mostra uma cara calma ou zangada, conforme o som

// >>> A EQUIPA ESCOLHE AQUI <<<
let LIMIAR = 150

basic.forever(function () {
    let som = input.soundLevel()
    if (som >= LIMIAR) {
        basic.showIcon(IconNames.Angry)
    } else {
        basic.showIcon(IconNames.Happy)
    }
    basic.pause(200)
})

Medir e mostrar a cara

Em ciclo contínuo, lê o som e compara com o limiar. Uma cara contente é o sinal visual que o grupo vai usar durante a tarefa — sem precisar de olhar para números.

basic.forever(function () {
    let som = input.soundLevel()
    if (som >= LIMIAR) {
        basic.showIcon(IconNames.Angry)
    } else {
        basic.showIcon(IconNames.Happy)
    }
    basic.pause(200)
})

Uma edição só, sempre a mesma: o valor de LIMIAR, no passo 01, entre a primeira tentativa e a ronda mais apertada.
