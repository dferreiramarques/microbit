Semáforo
humano

Um micro:bit não sabe nada além do que lhe chega. Recebe um sinal, espera um instante, passa-o adiante. Uma fila de oito pessoas com isto nas mãos é, sem ninguém perceber logo, uma rede de retransmissão.

350 ms por pessoa
Tempo até ao fim da fila: —
Sem sensores 1 variável editável Rádio grupo 9 Fila de 8 a 14 pessoas
O mecanismo

Receber, esperar,
passar adiante

Não há um centro a coordenar a fila. Cada micro:bit corre a mesma regra pequena, sem saber que está numa fila.

Início

Alguém carrega A

O primeiro da fila mostra um ícone e envia o sinal por rádio. É o único momento em que alguém decide alguma coisa.

Receção

Chega o sinal

Cada aparelho, ao receber, acende o ícone — é o momento visível, o que a pessoa ao lado vê e sabe que chegou a sua vez.

Espera e reenvio

Passa adiante

Depois de um atraso fixo, reenvia o mesmo sinal por rádio. Quem estiver a seguir na fila recebe-o e repete o processo.

Conceito

A demora
soma-se

Um único micro:bit passa o sinal quase de imediato. Mas numa fila de oito, o atraso de cada um soma-se ao anterior — é o mesmo mecanismo por trás de uma mensagem que demora a atravessar uma rede de verdade, ou de uma onda de adeptos num estádio.

Preparação

Uma fila,
uma ordem

Não há configuração por aparelho — todos correm o mesmo código. A única preparação é física: dispor os participantes em fila, com espaço entre cada um para o rádio não confundir quem está a duas posições de distância.

Programa

Código MakeCode

No MakeCode, abrir o separador { } JavaScript, colar, e voltar a Blocos. É o mesmo código para toda a fila — cada equipa cola isto inteiro e edita só uma coisa, a seguir, passo a passo.

semaforo-humano.ts · retransmissão com atraso 
// ===== SEMÁFORO HUMANO — microbit.monco.io =====
// recebe, espera, passa adiante

// >>> A EQUIPA ESCOLHE AQUI <<<
let ATRASO = 350

let ocupado = false

function receberOnda() {
    if (!ocupado) {
        ocupado = true
        basic.showIcon(IconNames.Yes)
        basic.pause(ATRASO)
        radio.sendString("ONDA")
        basic.pause(600)
        basic.showIcon(IconNames.SmallDiamond)
        ocupado = false
    }
}

input.onButtonPressed(Button.A, function () {
    basic.showIcon(IconNames.Yes)
    radio.sendString("ONDA")
})

radio.onReceivedString(function (receivedString) {
    if (receivedString == "ONDA") {
        receberOnda()
    }
})

radio.setGroup(9)
basic.showIcon(IconNames.SmallDiamond)

O atraso

ATRASO é o único valor do programa. É quanto tempo, em milissegundos, cada pessoa espera entre receber o sinal e reenviá-lo. Mudar este número antes de cada ronda da fila — é o que se está a testar.

// >>> A EQUIPA ESCOLHE AQUI <<<
let ATRASO = 350
02
Já vem assim

Quem começa

Só o primeiro da fila carrega no botão A. Mostra o ícone de imediato, sem esperar — o atraso só existe para quem recebe.

input.onButtonPressed(Button.A, function () {
    basic.showIcon(IconNames.Yes)
    radio.sendString("ONDA")
})
03
Já vem assim

Receber, esperar, passar adiante

Ao receber ONDA, o aparelho acende o ícone para quem está a olhar, espera ATRASO, e reenvia. O sinalizador ocupado impede que o mesmo aparelho reenvie duas vezes seguidas por ouvir ecos da fila.

radio.onReceivedString(function (receivedString) {
    if (receivedString == "ONDA") {
        receberOnda()
    }
})

Uma edição só, sempre a mesma: o valor de ATRASO, no passo 01, antes de cada ronda da fila.

Para onde
isto pode ir

  • Onda em círculo — fechar a fila num círculo e ver quantas voltas dá até alguém mandar parar
  • Duas ondas — arrancar de dois pontos da fila ao mesmo tempo e ver onde se cruzam
  • Ruído — um participante no meio da fila finge que não recebeu, uma vez em cada três, e o grupo descobre como isso muda o tempo total
