Gradiente

Cada micro:bit mede a luz onde está e mostra um número. Sem trocar uma palavra, o grupo tem de se organizar numa fila do mais escuro ao mais claro — só a olhar para os ecrãs uns dos outros.

Leitura 182 Claro
Sensor de luz · 0–255 1 variável editável Sem rádio Fila de 8 a 14 pessoas
O mecanismo

Uma leitura,
uma decisão

Não há rádio nesta atividade — cada aparelho só sabe o que mede em si próprio, e mostra-o. É o grupo, não o código, que organiza a informação.

Sempre

Mostra o número

O ecrã mostra continuamente a leitura de luz naquele ponto exato da sala — o valor muda se a pessoa se mexer.

Botão A

Verifica a zona

Compara a leitura com o limiar e mostra, por um instante, se está do lado escuro ou do lado claro.

Fora do código

O grupo organiza-se

Ordenar pela leitura, ou agrupar pela zona, é trabalho humano — o programa só informa, não decide nada por ninguém.

Conceito

O limiar é
uma escolha

Dois micro:bits lado a lado, na mesma luz, raramente dão o mesmo número exato — cada sensor tem a sua própria margem de erro. E decidir onde acaba "escuro" e começa "claro" não é uma medida, é uma escolha de quem programa. Mudar o limiar não muda a sala; muda quem fica de que lado.

LimiarEfeito
64Quase todos ficam do lado "claro"
128Divisão a meio, mas sensível a quem está na fronteira
192Quase todos ficam do lado "escuro"

Preparação

Uma sala
com variação de luz

Não há configuração por aparelho — todos correm o mesmo código. A preparação é do espaço: escolher uma sala com zonas visivelmente diferentes de luz (perto e longe da janela, luzes acesas só de um lado).

ZonaComo criar
EscuraPersiana fechada, luzes desligadas, um canto sem janela
MédiaLuz normal de sala, sem foco direto
ClaraJunto à janela ou por baixo de um foco
Programa

Código MakeCode

No MakeCode, abrir o separador { } JavaScript, colar, e voltar a Blocos. Cada equipa cola isto inteiro e edita só uma coisa, a seguir, passo a passo.

gradiente.ts · leitura de luz + limiar 
// ===== GRADIENTE — microbit.monco.io =====
// mostra a luz medida; o botão A verifica a zona

// >>> A EQUIPA ESCOLHE AQUI <<<
let LIMIAR = 128

basic.forever(function () {
    basic.showNumber(input.lightLevel())
})

input.onButtonPressed(Button.A, function () {
    if (input.lightLevel() >= LIMIAR) {
        basic.showIcon(IconNames.Yes)
    } else {
        basic.showIcon(IconNames.No)
    }
    basic.pause(900)
})

O limiar

LIMIAR é o único valor do programa — o número a partir do qual uma leitura conta como "claro". A escala vai de 0, escuro total, a 255, luz máxima.

Mostrar o número

Em ciclo contínuo, o ecrã mostra a leitura de luz naquele preciso momento e lugar. É o que a fila vai usar para se ordenar — sem precisar de saber mais nada do código.

basic.forever(function () {
    basic.showNumber(input.lightLevel())
})

Já vem assim

Verificar a zona

Ao carregar A, compara a leitura com LIMIAR e mostra um visto ou uma cruz — é a diferença entre um número contínuo e uma decisão de sim ou não.

input.onButtonPressed(Button.A, function () {
    if (input.lightLevel() >= LIMIAR) {
        basic.showIcon(IconNames.Yes)
    } else {
        basic.showIcon(IconNames.No)
    }
})

Uma edição só, sempre a mesma: o valor de LIMIAR, no passo 01, antes da segunda ronda da fila.

Para onde
isto pode ir

  • Dois limiares — escuro, médio, claro, três zonas em vez de duas
  • Rádio — cada aparelho anuncia a sua leitura por rádio; um 9.º aparelho recebe todas e calcula a média da sala
  • Ao contrário — em vez de mostrar o número, mostrar só o ícone da zona, e o grupo tem de se ordenar só com sim ou não
